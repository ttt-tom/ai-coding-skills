# Project working agreement

- Read project instructions, current diff, docs/ACTIVE_HANDOFF.md and docs/CODEMAP.md when relevant.
- One patch addresses one acceptance criterion or coherent defect; preserve unrelated work.
- Navigate by symbols; read necessary context completely, avoid unchanged repeated reads.
- If exploration stops producing evidence, construct an isolated test or state the blocker.
- Test providers, subprocesses and persistence must be isolated before execution.
- Report actual checks and unverified behavior; do not equate unit tests with production acceptance.
- Update handoff at transfer; document file ownership for concurrent work.
- No deployment, real paid calls, credential changes or publishing without applicable authorization.
- Add project-specific invariants here; do not copy another project's infrastructure assumptions.
